# Release review: v0.8.0

## Scope

Changed:
- Verification: 24 red-team cases (15 false verified fixed), success words and `expect=` negation in ten more
  languages, field and toast checks that wait only for timers the page set, error dialogs, soft 404s, error routes.
- Network: the guard chains to the user's `HTTP(S)_PROXY`; DNS-rebinding and WebSocket tests.
- Engines: Chromium runs in its OS sandbox where the host allows it (doctor WARN otherwise); Obscura WebSockets
  fail honestly and such pages move to Chromium; popup race on slow machines fixed (CI #43, #49).
- Duplicate guard: optional `key` on `act` / `fill_form`, kept for 24 h across sessions, claimed atomically.
- Real-site canary (`scripts/canary.py`, weekly `canary.yml`).

Interface: `act` and `fill_form` gain an optional `key` (schemas 699 → 724 proxy tokens, ~+68 real tokens per
request; budget 750 by maintainer decision). Nothing removed; clients that don't pass `key` behave as before.
