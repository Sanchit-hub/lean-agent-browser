# Release review: v0.6.0

## Scope

Changed:
- When an action counts as `verified`: 14 false-verified runs fixed, plus ARIA checkboxes.
- Form validation is checked before every submit.
- A connect-time network guard for both engines, which fixes the redirect-to-private SSRF.
- A reliability workflow, an upgrade test, and docs.

Not changed: MCP tool names or parameters, CLI commands, Python API, config keys.

## Evidence

| Check | Result |

| Redirect SSRF regression test | fails with the guard off, passes with it, on both engines |

## Security

- **Fixed:** a public URL that redirected to localhost, LAN or 169.254.169.254 loaded on Chromium.
- **New component:** `netguard.py`, a proxy on 127.0.0.1 with a random port, one per BrowserManager. It only
  refuses or relays connections. It doesn't inspect HTTPS (that goes through CONNECT tunnels) and logs
  only the hostnames it blocks.
- **Known limit:** with `HTTP(S)_PROXY` set, the guard is off.
- Chromium still runs without its own OS sandbox, as documented.

## Compatibility

- Some actions that used to say `verified` now say `unverified` or `blocked`:
  - the same form came back,
  - a dialog was answered and nothing else changed,
  - a submit opened a new tab,
  - a "not saved"-style message appeared,
  - the form fails its own validation.
- These were overclaims. An agent that relied on them now gets the honest status. Schemas are unchanged.

## Installation

The clean install, `setup`, `doctor`, MCP round trip, pipx install, and upgrade from v0.5.0 pass in CI on all
three platforms.

## External validation

None yet. No outside users have tried 0.5.0 or 0.6.0.

## Known limitations

These are in the README, `docs/RELIABILITY.md` and `SECURITY.md`:
- success and error words are English-only,
- other clicks are verified by any page change,
- the guard is off when `HTTP(S)_PROXY` is set,
- Chromium runs without its own sandbox,
- no PyPI release yet.

## Rollback

`pipx install --force "git+https://github.com/Sanchit-hub/lean-agent-browser@v0.5.0"`, then `leanb setup`.
No config or data migration.

## Decision

**SHIP as a tagged preview (`v0.6.0`).** Every gate that can be checked without outside people passes.

**HOLD the wide release and PyPI** until three first-time users complete onboarding unaided (release gate)
and the maintainer sets up trusted publishing.
