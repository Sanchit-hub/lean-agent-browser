# Release review: v0.7.0

## Scope

Changed:
- `expect=` needs fresh, non-negated evidence for clicks and submits, and is checked in a new tab when one opens.
- Common error words in ten languages are recognised.
- Concurrent Python API calls are serialized.
- Engine crashes give a clear error.
- New contract, isolation, stdout and crash tests.
- Audit docs (`docs/audits/cycle-002.md`, `docs/PRODUCT_TRUTH.md`).

Not changed: MCP tool names and schemas (now locked by `tests/contract/mcp_tools.json`), CLI, config, Python
API signatures.
